
# 🚗 Car Price Prediction using Machine Learning

## 📌 Overview

This project predicts the selling price of used cars using Machine Learning. The model analyzes different features such as car brand, manufacturing year, fuel type, transmission, kilometers driven, and owner type to estimate the market price accurately.

The goal of this project is to build a regression model that helps buyers and sellers estimate a fair price for a used car.
